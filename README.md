# React CRUD with Redux

A simple CRUD (Create, Read, Update, Delete) application built with **React** and **Redux**.
This project demonstrates how to manage global state with Redux while performing basic CRUD operations.

---

## 🚀 Features

* View list of items (Read)
* Add a new item (Create)
* Edit an existing item (Update)
* Delete an item (Delete)
* Global state management with Redux
* Modular and reusable components

---

## 🛠️ Tech Stack

* **React** (UI library)
* **Redux** (state management)
* **Redux Toolkit** (for cleaner Redux code)
* **React Redux** (Redux bindings for React)
* **React Router** (for navigation)
* **Tailwind CSS / CSS Modules** (styling — optional)

---

## ⚙️ Installation & Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/react-crud-redux.git
   cd react-crud-redux
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start development server:

   ```bash
   npm run dev
   ```

4. Open in browser:
   [http://localhost:5173](http://localhost:5173)
